# 🖼️ Binary Image Classifier

A powerful and easy-to-use binary image classification tool! This project leverages modern machine learning techniques to accurately distinguish between two classes of images.

---

## 🚀 Features

- Fast and efficient training pipeline
- Customizable model architecture
- Evaluation metrics and visualization
- Simple prediction API

---

## 🛠️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/rajivchandak25/Binary-Image-Classifier.git
cd Binary-Image-Classifier
pip install -r requirements.txt
```

---

## 📦 Requirements

See [`requirements.txt`](requirements.txt) for a full list.

---

## 💡 Usage

Train and evaluate the classifier by running:

```bash
python train.py --data_dir ./data --epochs 20
```

Predict with a trained model:

```bash
python predict.py --model_path ./model.pth --image_path ./test.jpg
```

---

## 📁 Dataset

Place your training and validation images in the `data/` directory, organized into two subfolders (one for each class).
